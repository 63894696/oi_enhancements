## 关键设计点

**1. 早失败避免白算 PoW(2s 浪费)**:retract 前先 read history 找父帖 +
校 author_fp == 自己 + 校未 retracted/taken_down。任一失败直接返 error 不进
PoW 循环,失败响应还带 rich error 信息(hint + your_fp + post_author_fp 给用户
排查 marketplace_identity.key 丢/重生/换机器)。

**2. retract 帧入 canon(签名覆盖)**:跟 publish 同模式 — 父帖 id、ts、reason
都进 signed_view,attack 者改任一字段验签失败。 PoW 仍需(抗 spam retract,
跟 post 一致)。

**3. marketplace ext 用同一身份签名**(~.prisir/marketplace_identity.key):
「marketplace 这个 ext」专用,跟 fbmodal 反馈身份 / chatroom 身份解耦。
市场身份丢了 = 不能自删(只能请运营者撤下),这是协议层面正确的设计。

**4. web UI 仅自己可见 🗑️**:wfMarketRefresh 调 market.identity 拿自身 fp,
isMine 判定后只渲染按钮 + ★ 标记。其他人发的帖看不到按钮,UX 简单,
不在前端做 author 角色判断。
