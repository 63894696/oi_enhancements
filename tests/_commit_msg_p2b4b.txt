feat(p2.5+b-4.b): AI agent 触发已存 workflow — run_task({task_name}) 模糊匹配 + 简表注入

B-4 ship 后 AI agent 能用 run_task({name, dag}) 内联生成 workflow,但用户常说
「再跑一遍 daily_summary」「那个 review 工作流再来一遍」 — 已存 task 在 wfmodal 里
手动 ▶ 可一键跑,对话里却要 LLM 重生成 dag(可能跟原版略有偏差)。B-4.B 把
run_task 扩成双模式 + system prompt 注入 task 简表,LLM 直接用 task_name 命中。

关键改动:

cli (prisIragent_cli.py):
  - run_task tool def 描述改两模式叙述(Inline dag / Re-run existing);
    加 task_name 字段(子串匹配,大小写不敏感);required 改空数组允许二选一
  - 新模块顶层 helper _task_runner_rpc(method, params, timeout) —
    B-4 的 _rpc 闭包提到顶层,让 _t_run_task + _t_run_task_by_name 共用
  - _t_run_task 加 task_name 分支:优先 task_name;啥都没传返 error+hint
    引导选模式;task_name + wait 参数透传;legacy (name+dag) 路径不变
  - 新 _t_run_task_by_name(task_name, wait) 函数:
      1) task.list limit=100
      2) exact 优先(case-insensitive),再 substr 子串
      3) 多命中无精确 → error + candidates[0:10] + hint disambiguate
      4) 零命中 → error + hint 列前 10 个已存 name 引导改名
      5) 命中 → task.run(id, wait) 返 {task_id, task_name, matched_by,
         run_id, status, queued, note}
  - 子代工具集剔除列表加 "run_task"(同 spawn_subagent / run_workflow 防
    agent 递归派单)

web (prisIragent_web.py):
  - _shell_system_prompt 函数末尾追加 task 简表注入:
      _ext_rpc_call("task-runner", "task.list", {"limit":100}, timeout=2s)
      → markdown 简表(name/id/节点数/trigger),最多 50 行
      → task-runner 没启 / 0 task / RPC 异常 → 一律静默不注入(timeout=2s
        快速失败,不拖对话启动)
