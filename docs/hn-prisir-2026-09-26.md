### B2. hn_search provider 注册到 web_search.py(**始终注册**)

```python
def hn_search_provider(query: str, limit: int = 10) -> list[dict[str, Any]]:
    """HN search_by_date → 标准 search result list。"""
    try:
        from prisir_work import hn_bridge as _hn
        r = _hn.hn_search(query, sort="by_date",
                         limit=min(max(limit, 1), 30),
                         min_points=5,           # 过滤低分
                         timeout=10.0)
        if not r.get("ok"):
            return []
        return [{"url": it["url"], "title": it["title"],
                 "snippet": (it.get("snippet", "")
                             or f"{it.get('points', 0)}pt · "
                                f"{it.get('num_comments', 0)}cmt")}
                for it in r.get("results", []) if it.get("url")]
    except Exception:
        return []

register_provider("hn_search", hn_search_provider)
```

## Risks

| 风险 | 缓解 |
|------|------|
| Algolia API 限流 / 5xx | `hn_health` 探活 + provider 失败返空(走其它 provider) |
| 关键词噪音(HN 太多同标题) | `min_points = 5` 过滤,provider 默认用此 |
| HN 顶级文本不含外链 URL | `story_url` 字段 fallback + HN item 页 URL 兜底 |
| HN 评论树太深 | 单 item 端点返 children id 列表,不递归展开(避免炸 LLM context) |
| Algolia vs Firebase 不一致 | 全用 Algolia(更现代 + JSON 友好);Firebase 不再 ship |
| 测试时真发网络(verify check_hn_health_live) | 加注释 + SkipHttp 时此 check 也走(单 health 一次探活,可控) |

## 数据流

```
主对话「HN 上 claude code 怎么评价」
  ↓ LLM 解析出 [[EXEC: web.hn.search query="claude code" min_points=10]]
  ↓ endpoints._web_hn_search
  ↓ hn_bridge.hn_search → urllib GET /search_by_date?...
  ↓ {ok, query, results[{url,title,snippet,points,num_comments}], total_hits}
  ↓ 前端展示列表 + 分数/评论数 + LLM 后续总结

主对话「HN 上最近热门 AI 帖」
  ↓ [[EXEC: web.hn.top limit=10]]
  ↓ hn_top_stories → /search?numericFilters=points>0 → 10 条
  ↓ 前端渲染

主对话 → 多源 search RRF:
  web_search.search("claude code review")
    ├─ ddg_html      → 5 results
    ├─ baidu         → 5 results
    ├─ bing_public   → 5 results
    ├─ exa_search    → 5 results (env 在)
    ├─ gh_search     → 5 results (gh 在)
    └─ hn_search     → 5 results (始终)
  ↓ RRF 融合 → top 5 → fetch + LLM
```
